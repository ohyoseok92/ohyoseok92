# 오효석

AI 서비스와 백엔드를 개발합니다. LLM Agent와 RAG를 서비스 흐름에 연결하고, 답변의 근거·입력 검증·실패 처리를 코드로 확인하는 데 관심이 있습니다.

## 대표 프로젝트

| 프로젝트 | 직접 확인할 수 있는 내용 |
| --- | --- |
| [금융상품 Agent](https://github.com/ohyoseok92/finance-agent-miraeasset-ai-festival) | 금융상품 데이터를 조회·비교하고 답변 근거를 검증하는 서비스 |
| [RAG 인용 캐시 실험](https://github.com/ohyoseok92/rag-citation-cache-demo) | 원문 수정 뒤 오래된 인용이 남는 문제를 합성 데이터로 재현하고, 원문 해시를 캐시 키에 반영한 수정안을 검증. [브라우저 시연](https://rag-citation-lab-oh6428.oh6428.chatgpt.site/) |
| [Room 3D Explorer](https://github.com/ohyoseok92/room-3d-explorer) | 사진 기반 3D 점군 생성과 브라우저 탐색. GPU 경로와 브라우저 대체 경로를 구분 |
| [NEXMILL 웹사이트 데모](https://github.com/ohyoseok92/nexmill-b2b-demo) | 가상 제조기업의 반응형 소개·제품 상세·문의 접수와 제작자용 문의함. [공개 시연](https://nexmill-industrial-demo.oh6428.chatgpt.site/) |

NEXMILL과 RAG 인용 캐시 실험은 자체 제작 시연이며 고객 납품 실적이 아닙니다. 각 저장소의 README에 구현 범위와 검증 방법, 남은 한계를 적었습니다.

주로 Python, FastAPI, React, TypeScript와 Cloudflare Workers를 사용합니다.
